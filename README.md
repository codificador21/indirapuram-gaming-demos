# codificador21.github.io

Landing page, plus unofficial concept website demos built as unsolicited design proposals.

Each demo is **not affiliated with, endorsed by, or operated by** the business it is named
after. Every demo page carries a visible disclaimer bar and a `noindex, nofollow` tag, and
`robots.txt` disallows crawling of the demo paths.

Rates, opening hours and any contact details that are not publicly listed render as
*to be confirmed* rather than being filled in with invented values. All photographs are
public-domain (CC0) stock placeholders — none of them show the venue.

## Expense tracker (`expense-tracker/`)

A separate, self-contained app lives in [`expense-tracker/`](expense-tracker/): a personal expense
tracker (Next.js + Postgres) that captures bank SMS/email automatically. It is unrelated to the
static demo site above and does not affect it. Start with
[`expense-tracker/MORNING_REPORT.md`](expense-tracker/MORNING_REPORT.md).
